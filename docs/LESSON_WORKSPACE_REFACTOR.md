# 课次工作区与入口收敛

本轮把学习成果作为主入口：课程只有「课次学习 / 公共资料 / 教学网」，课次只有「讲义与练习 / 本节文件」。讲义与配套练习优先呈现，其他生成资料次之；助手为辅助入口。大纲、来源、范围配置放在展开项。教学网合并动态与作业、资源、录播，历史课程练习与旧版独立笔记保留在「历史内容」，不猜测归属、不自动迁移。

## 已实现的数据边界

- Material 原件按课程 SHA 去重；`coursePublic` 缺省为 true，兼容历史资料。在课次直接上传的新增文件为 false，上传同时关联该课次；公共文件加入课次时仍保留公共身份。
- `Lesson.materialRefs` 是本节文件索引，包含 assetId 和可选 blockIds；不同于原有按大纲主题组织的 `selections`。从课次移除引用不会删除原件。需要重新加入移出的专属文件时，可重新上传相同文件，仍会去重。
- 本节输入包含指定文件/片段、关联转写稿、公共库相关原文。未完成转写的录播只显示缺失提示，不假装可读。
- 公共库自动检索目前是确定性的中文双字/英文词匹配，查询依据课次标题、范围与大纲；缺少明确范围/大纲时，补充本节已选原文开头的有限内容。命中标题附带后续有限段落，到下一标题停止；不是语义向量检索。用户需要精确范围时，应手动选择原文片段、关闭自动参考或排除片段。
- 上下文总预算 60,000 字符；单个指定资料 30,000，单份转写 25,000，公共自动参考合计 12,000。只保留完整块，超预算会明确提示遗漏。以快照 hash 校验创建会话时的输入，生成讲义或配套资料时持久化快照，讲义另存引用来源。
- 课次助手单独创建内存会话，只注册读取本节上下文、保存本节讲义、保存本节成果三个工具。没有课程全文读取、任意文件系统、跨课次搜索、录播转写或教学网操作工具，也不注入课程级 notes 提示文件。
- 工具调用逐次检查课次 revision 和来源有效性。人工编辑、范围变更或已读原文被替换后，旧会话不能继续保存。保存讲义继续保留原有乐观并发保护。
- 本节配套练习和其他成果存入 `Lesson.artifacts`，练习题目/答案分开显示；目前成果内容以 SQLite 为准，讲义仍镜像至 `lessons/<lessonId>/lecture.md`。

## @ 与 / 的行为

输入 @ 可按名称选择已索引文件，显示可移除的引用标签，后端使用稳定 assetId 验证。课次助手只显示本节资料和公共资料，额外引用加入当前课次上下文；更改引用会新建会话，不继承旧模型历史。公共教材需要精确章节时，应先在本节文件中选定块范围。

课程级助手选择 @ 文件后进入有预算的文件问答会话，只能读取所选文件，暂不提供保存型 Skill；课次生成应从课次入口进行。旧版独立笔记默认沿用历史来源范围；使用 @ 后同样进入所选文件问答，不改变历史数据。

输入 / 按名称选择 Skill，支持方向键、Enter/Tab、Escape；选择只填入输入框，用户可补充要求后发送。课次提供整理本节、生成自测；课程助手继续提供教学网同步、独立笔记、作业草稿等工作流。

## 下一轮重构建议

1. **统一助手入口已于 2026-09-10 落地。** 课程头部保留一个「学习助手」，随当前页面选择课程/课次范围。各范围保留独立内存会话，具体行为见下方。
2. **教学网集中处理同步与待办。** 页面保留资料选择、下载状态、公告和作业提交审批；同步资料、归类、复习规划等批量操作放到 / Skill。审批和身份验证继续使用可核查的明确界面。
3. **文件索引的逐步编辑。** 先展示文件名、来源、解析状态、选定页码；选择后才显示片段预览。增加教材目录/连续页码选择、孤立专属文件回收入口，以及录播/转写在课次内的后续关联操作。
4. **生成前的上下文工作台。** 自动选材先做建议，展示章节覆盖、遗漏和预算，用户可确认/排除。改用章节感知的混合检索并补充相关性评测；长度预算改为按目标模型 token 计算。
5. **成果统一与历史迁移。** 提供人工将旧笔记/旧练习归入某节课的操作；新增成果版本、导出与修订入口。归属由用户确认，避免以文件名猜测后静默搬迁。

不再为每一种生成工作流增加首页卡片。稳定导航按对象组织（课次、公共资料、教学网）；低频动作进入对象内部菜单或 / Skill。

自动化覆盖课次资料与公共资料隔离、精确片段选择/排除、旧 contextId、跨课程引用、文件去重、人工编辑冲突、来源替换后失效、会话工具注册范围和无课程提示注入。浏览器覆盖拖入/选择文件、来源预览、@ 与 / 键盘选择、保存后重载、公共库过滤、编辑保护和窄屏布局。

浏览器和模型联调使用标题明确标注「联调」的独立测试课程。未运行真实视频 ASR，未提交作业。

当前验证结果：core 58、server 23、web 3，共 84 项通过；typecheck 与 build 通过。配置的 `zai / glm-5.3-flash` 已在隔离测试课次完成真实工具调用，34 秒内保存讲义及题目/答案分离的配套练习。证据在 `.pku-study/integration/results/lesson-workspace-2026-09-09/`。


## 2026-09-10：统一助手与工作流入口

- 移除课次标题旁重复的助手按钮，全部生成操作使用同一个学习助手侧栏。侧栏明确显示课次名称、原文范围和成果保存位置。
- 课程页面（公共资料、教学网动态、资源、录播）共享课程会话；每个课次各自保留对话、输入草稿、引用标签和执行状态，切回页面可继续。独立笔记仍按所选文件集合建立专用会话，不扩大历史功能的数据范围。
- 页面切换或收起侧栏不销毁正在执行的会话；后台任务固定在创建时的课次，完成后通过提示返回对应课次。成果完成后刷新课次内容，公共资料整理完成后刷新公共库。离开整个课程或刷新浏览器仍会结束这些内存会话；只有原有命名课程会话持久化。
- 已有输入草稿时点击「生成讲义/练习」会保留草稿并追加要求，待用户发送。新对话按钮清空当前对话并重新获取上下文，保留未发送草稿；修改 @ 引用同样开启新的限定范围会话。人工文档编辑仍由 revision 校验保护。
- / 菜单使用共享 Skill 目录，并按课次/课程/限定文件问答范围筛选。课次新增「复习提纲」，使用原有受限工具保存到本节其他资料；课程新增「整理公共资料」，检查解析状态和用途，不移动或删除文件。选择 Skill 只填入输入框，不立即执行。
- 其他资料区不再增加单独的「生成复习提纲」按钮，统一从 / 选择。会话命名与恢复放入展开项；教学网的课程检索、重建索引和本地路径收进「课程检索与维护」。下载、同步状态、身份验证和作业审批仍保留直接界面。

本轮验证：core 58、server 23、web 6，共 87 项；构建与类型检查通过。新增浏览器测试用延迟的模拟模型响应检查范围切换、草稿保留、后台完成提示、收起不取消、Skill 选择与窄屏显示。该测试验证客户端会话路由，不等同于再次验证真实模型生成质量。证据位于 `.pku-study/integration/results/unified-assistant-2026-09-10/`。

课次列表按日期从早到晚排序，无日期统一置底；同一天按标题自然排序。新建表单首先选择是否关联录播，其次选择教学网/已上传录播，再填写标题、日期。教学网录播优先使用原始显示日期，缺失时将时间戳按北京时间转换；多段录播取最早可用日期。手动日期优先，前端可恢复录播日期。上传录播无授课日期元数据时保留空白，不使用上传或同步时间。历史已关联但无日期的课次读取时也会采用可用录播日期，已有明确日期保持原值。
